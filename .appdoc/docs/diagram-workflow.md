# C4 Mermaid Diagram Workflow

## Overview

AppDoc uses a Mermaid-first workflow for C4 architecture diagrams. The workflow is deterministic by default and can be AI-enhanced with `/appdoc.diagrams`.

## Workflow Steps

### Step 1: Generate Baseline Mermaid C4 Diagrams (Deterministic)

**Script**: `generate-c4-mermaid-diagrams.ps1`

**Purpose**: Analyze codebase and generate baseline Mermaid C4 markdown files.

**Command**:
```powershell
.\\.appdoc\scripts\powershell\generate-c4-mermaid-diagrams.ps1 `
  -CodebasePath ".\MySolution.sln" `
  -OutputPath ".\docs" `
  -DiagramLevels All
```

**Output**: markdown files in `docs/diagrams/`
- `c4-context.md` - C4 System Context diagram
- `c4-container.md` - C4 Container diagram

### Step 2: AI Enhancement (Optional)

**Command**: `/appdoc.diagrams`

**Purpose**: Enrich Mermaid diagrams with evidence-based actors, integrations, and protocol details discovered in code.

### Step 3: Consume in Documentation

Mermaid diagrams are embedded in markdown and viewable directly in Markdown renderers that support Mermaid.

## Complete Example

```powershell
cd C:\Projects\MyApplication

.\\.appdoc\scripts\powershell\generate-c4-mermaid-diagrams.ps1 `
  -CodebasePath ".\MyApplication.sln" `
  -OutputPath ".\docs" `
  -DiagramLevels All `
  -Force

# Optional enhancement in Copilot Chat:
# /appdoc.diagrams
```
